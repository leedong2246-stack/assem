배열 : 배열 동일한 데이터 타입에 기억공간 <br>
Structures: 여러 데이터를 하나로 묶는다. <br>
Macros: 여러 명령어를 하나의 이름으로 묶는다. <br>
공용체 : 여러 개의 멤버가 동일한 메모리 공간을 공유하는 자료형. <br>
구조체 참조 : 구조체에 저장된 특정 데이터에 접근하는 것이다. <br>
IPO : 입력(Input), 처리(Process), 출력(Output)의 약자로 프로그램의 기본 동작 구조. <br>
변수 : 메모리 주소를 대표하는 기호이다. <br>
인다이렉 : 데이터가 어디에 있는지 직접 지정하는 것이 아니라, 데이터가 저장된 주소를 통해 찾아가는 것이다 <br>
함수 : 변수와 여러개의 변수를 묶은거, 클래스 : 함수와 변수를 묶은거 <br>
Required : REQ, 필수로 있어야함
optional : 선택 있어도 되고 없어도 됨
