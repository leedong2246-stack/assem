4. Declare an array of Triangle structures. Write a loop that initializes Vertex1 of each triangle
to random coordinates in the range (0...10, 0...10).
-> 
.data
TRIANGLE_COUNT = 10
triangles Triangle TRIANGLE_COUNT DUP(<>)

.code
mov ecx, TRIANGLE_COUNT
mov esi, OFFSET triangles

L1:
    ; X 좌표 무작위 생성 (0 ~ 10)
    mov eax, 11
    call RandomRange
    mov (Triangle PTR [esi]).Vertex1.X, ax

    ; Y 좌표 무작위 생성 (0 ~ 10)
    mov eax, 11
    call RandomRange
    mov (Triangle PTR [esi]).Vertex1.Y, ax

    ; 다음 Triangle 요소로 이동
    add esi, SIZEOF Triangle
    loop L1

5. Write a macro named mPrintChar that displays a single character on the screen. It should
have two parameters: this first specifies the character to be displayed and the second speci
fies how many times the character should be repeated. Here is a sample call:
	mPrintChar 'X',20
-> 
mPrintChar MACRO charValue, repeatCount
    LOCAL L1
    push ecx
    push eax

    mov ecx, repeatCount
    mov al, charValue
L1:
    call WriteChar
    loop L1

    pop eax
    pop ecx
ENDM

6. Write a macro named mGenRandom that generates a random integer between 0 and n 1.
Let n be the only parameter.
-> 
mGenRandom MACRO n
    mov eax, n
    call RandomRange    ; EAX에 0 ~ (n-1) 무작위 정수 생성 결과 저장
ENDM

7. Write a macro named mPromptInteger that displays a prompt and inputs an integer from
the user. Pass it a string literal and the name of a doubleword variable. Sample call:
.data
minVal DWORD ?
.code
mPromptInteger "Enter the minimum value", minVal
-> 
mPromptInteger MACRO promptText, targetVar
    LOCAL promptStr
    .data
    promptStr BYTE promptText, 0

    .code
    push edx
    mov edx, OFFSET promptStr
    call WriteString
    call ReadInt
    mov targetVar, eax
    pop edx
ENDM
