Programming Exercises
1. Integer Expression Calculation
Using the AddTwo program from Section 3.2 as a reference, write a program that calculates the
following expression, using registers: A = (A + B) − (C + D). Assign integer values to the EAX,
EBX, ECX, and EDX registers.
-> 
.386
.model flat, stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.code
main PROC
    ; 예시 값 설정: A=10(EAX), B=5(EBX), C=3(ECX), D=2(EDX)
    mov eax, 10      ; EAX = A
    mov ebx, 5       ; EBX = B
    mov ecx, 3       ; ECX = C
    mov edx, 2       ; EDX = D

    add eax, ebx     ; EAX = A + B (15)
    add ecx, edx     ; ECX = C + D (5)
    sub eax, ecx     ; EAX = (A + B) - (C + D) (10)

    INVOKE ExitProcess, 0
main ENDP
END main

5. Listing File for AddTwoSum
Generate a listing file for the AddTwoSum program and write a description of the machine code
bytes generated for each instruction. You might have to guess at some of the meanings of the
byte values.
-> 
00000000  B8 00000005        mov eax, 5
00000005  83 C0 06           add eax, 6

B8 00000005 (mov eax, 5):
B8: EAX 레지스터에 32비트 즉시값(Immediate value)을 이동하라는 연산 코드(Opcode).
00000005: 피연산자 값 5를 리틀 엔디안 32비트(4바이트) 형태로 표현한 것 (05 00 00 00).
83 C0 06 (add eax, 6):
83: 8비트 정수 값을 32비트 레지스터에 덧셈하는 연산 코드.
C0: EAX 레지스터를 대상으로 지정하는 ModR/M 바이트.
06: 더해지는 값인 6 (1바이트로 축소 표기됨).

6. AddVariables Program
Modify the AddVariables program so it uses 64-bit variables. Describe the syntax errors gener
ated by the assembler and what steps you took to resolve the errors.
-> 
발생하는 오류:
32비트 모드어셈블러(ML.EXE)에서 64비트 레지스터(RAX, RBX 등)를 직접 사용하려고 하면 "invalid instruction operands" 또는 "instruction operand must have size" 등의 구문 오류가 발생합니다.
64비트 메모리 변수(QWORD)를 32비트 레지스터(EAX)에 MOV 명령어로 직접 복사하려고 하면 "operand types do not match" (피연산자 타입 불일치) 오류가 발생합니다.
오류 해결 조치:
방법 A (32비트 환경 유지 시): 64비트 변수를 32비트 두 조각(하위 32비트, 상위 32비트)으로 분할하여 ADD 및 ADC (Carry를 포함한 덧셈) 명령어를 통해 계산합니다.
방법 B (64비트 환경 전환 시): 프로젝트의 빌드 타깃을 x64로 변경하고 64비트 전용 어셈블러(ML64.EXE)를 사용하도록 설정한 후, 64비트 레지스터(RAX, RBX)를 사용하여 QWORD 변수를 처리합니다.
