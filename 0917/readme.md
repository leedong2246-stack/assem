명령어 : CPU가 실행 시간에 실제로 수행하는 기계어 명령이다 <br>
지시어 : 어셈블러 프로그램에게 소스 코드를 어떻게 변환(컴파일)할지 지시하는 명령으로, 실행 시간에 실행되지 않으며 대소문자를 구분하지 않는다 <br> 
라벨 (Label): 코드나 데이터의 위치(메모리 주소)를 나타내는 이름. <br>
니모닉 (Mnemonic): 수행할 동작을 나타내는 명령어 이름 (예: MOV, ADD). <br>
피연산자 (Operand): 명령어가 연산할 데이터 대상 (값, 레지스터, 메모리 주소). <br>
주석 (Comment): 코드 설명을 위한 문장 (세미콜론 ; 또는 COMMENT ! ... ! 블록 주석 사용). <br>
코드 라벨 : 실행할 명령어의 위치를 나타내며, 뒤에 콜론(:)을 붙다. <br>
데이터 라벨 : 변수의 위치를 나타내며, 뒤에 콜론(:)을 붙이지 않는다. <br>
식별자 규칙: 문자로 시작해야 하며, 숫자로 시작할 수 없다. <br>
BYTE / SBYTE	8비트 (1바이트)	부호 없는 8비트 정수 / 부호 있는 8비트 정수 <br>
WORD / SWORD	16비트 (2바이트)	부호 없는 16비트 정수 / 부호 있는 16비트 정수 <br>
DWORD / SDWORD	32비트 (4바이트)	부호 없는 32비트 정수 / 부호 있는 32비트 정수 <br>
QWORD	64비트 (8바이트)	64비트 정수 (부호 구분 없이 사용) <br>
TBYTE	80비트 (10바이트)	10바이트 크기의 Packed BCD 정수 또는 실수 저장용 <br>
Packed BCD는 10진수 숫자 두 자리를 1바이트(8비트)에 저장하는 방식. <br>
스택 메모리 할당 (.STACK): 프로그램이 사용할 스택 영역의 크기(예: .stack 4096(4096은 스택에 할당할 메모리 크기))를 지시어로 선언하여 예약합니다. <br>
