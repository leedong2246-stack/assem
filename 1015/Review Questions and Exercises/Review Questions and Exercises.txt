it could accumulate an array of 16-bit words? Create such a version of ArraySum and test it.
포인터 증가값을 4에서 2로 변경 (add esi, 2)
16비트 데이터를 읽어 32비트 누적기(EAX)에 더하도록 수정 (movzx ebx, WORD PTR [esi] 후 add eax, ebx)
ArraySum16 PROC
    push esi
    push ecx
    push ebx
    mov  eax, 0
L1:
    movzx ebx, WORD PTR [esi]
    add   eax, ebx
    add   esi, 2
    loop  L1
    pop   ebx
    pop   ecx
    pop   esi
    ret
ArraySum16 ENDP
