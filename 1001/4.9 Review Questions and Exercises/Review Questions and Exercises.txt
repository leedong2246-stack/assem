1. What will be the value in EDX after each of the lines marked (a) and (b) execute?

18. What will be the value of the destination operand after each of the following instructions
execute in sequence?

mov  ax,var2		; a. -> AX = 1000h (var2[0])
mov  ax,[var2+4]		; b. ->  AX = 3000h (var2+4 바이트 위치 = 3번째 WORD)
mov  ax,var3		; c. -> AX = FFF0h (var3[0] 값인 -16을 16진수로 표현)
mov  ax,[var3-2]		; d. -> AX = 4000h (var3 바로 전 2바이트 메모리 위치 = var2의 마지막 값)

19. What will be the value of the destination operand after each of the following instructions
execute in sequence?

mov    edx,var4		; a. -> EDX = 00000001h (var4[0])
movzx  edx,var2		; b. -> EDX = 00001000h (var2[0]을 MOVZX로 32비트 zero-extension)
mov    edx,[var4+4]	; c. -> EDX = 00000002h (var4+4 바이트 위치 = 2번째 DWORD)
movsx  edx,var1		; d. -> EDX = FFFFFFFCh (var1[0] 값인 -4 / FCh를 MOVSX로 32비트 sign-extension)
