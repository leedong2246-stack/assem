
1번
[문제] 32비트 모드에서 스택 포인터(ESP) 외에 스택 프레임 내의 변수를 가리키는 데 주로 사용되는 레지스터는 무엇인가?
[정답] EBP (Extended Base Pointer)
[해설] EBP 레지스터는 스택 프레임의 기준 주소를 가리키는 베이스 포인터로 사용되어, 스택에 저장된 매개변수나 지역 변수에 안정적으로 접근할 수 있게 해줍니다.

2번
[문제] CPU 상태 플래그(Status Flags) 4가지 이상의 이름을 쓰시오.
[정답] 캐리 플래그(CF), 제로 플래그(ZF), 부호 플래그(SF), 오버플로 플래그(OF)
[해설] EFLAGS 레지스터에 위치하며, 산술 및 논리 연산 결과의 상태(자릿수 넘침, 0 여부, 음수 여부, 부호 오버플로 등)를 기록합니다.

3번
[문제] 부호 없는(Unsigned) 산술 연산 결과가 목적지 피연산자의 크기를 초과하여 자릿수 넘침이 발생했을 때 1로 설정되는 플래그는 무엇인가?
[정답] 캐리 플래그 (CF, Carry Flag)
[해설] CF는 부호 없는 정수 연산에서 표현 가능한 최고위 비트를 넘어가는 올림(Carry)이나 빌림(Borrow)이 발생했을 때 set(1)됩니다.

4번
[문제] 부호 있는(Signed) 산술 연산 결과가 범위를 초과하거나 미달하여 표현할 수 없을 때 1로 설정되는 플래그는 무엇인가?
[정답] 오버플로 플래그 (OF, Overflow Flag)
[해설] OF는 부호 있는 정수 연산 결과가 비트 표현 범위(예: 8비트의 경우 -128 ~ +127)를 벗어났을 때 set(1)됩니다.

5번
[문제] (참/거짓) 레지스터 피연산자 크기가 32비트이고 REX 접두사가 사용될 때, R8D 레지스터를 프로그램에서 사용할 수 있다.
[정답] 참 (True)
[해설] 64비트 모드에서는 REX 접두사를 통해 확장된 레지스터(R8~R15)에 접근하며, R8D는 64비트 R8 레지스터의 하위 32비트 영역을 의미합니다.

6번
[문제] 산술 연산 또는 논리 연산 결과가 음수일 때 1로 설정되는 플래그는 무엇인가?
[정답] 부호 플래그 (SF, Sign Flag)
[해설] SF는 연산 결과의 최상위 비트(MSB, Most Significant Bit) 상태를 그대로 반영하므로, 결과가 음수(최상위 비트가 1)이면 1로 설정됩니다.

7번
[문제] CPU 내부에서 부동소수점(실수) 연산을 담당하는 전용 장치는 무엇인가?
[정답] FPU (Floating-Point Unit, 부동소수점 처리 장치)
[해설] FPU는 정수를 다루는 ALU와 달리 실수의 가산, 감산, 승산, 제산 및 수학적 함수 계산을 수행하는 전용 하드웨어입니다.

8번
[문제] 32비트 프로세서에서 각각의 부동소수점 데이터 레지스터(ST0~ST7)는 몇 비트 크기를 갖는가?
[정답] 80비트
[해설] x87 FPU의 내부 데이터 레지스터 스택은 높은 정밀도의 계산을 위해 IEEE 754 확장 정밀도 형식인 80비트 크기를 사용합니다.

9번
[문제] (참/거짓) x86-64 명령어 세트는 이전의 x86 (32비트) 명령어 세트와 하위 호환성(Backward-compatible)을 유지한다.
[정답] 참 (True)
[해설] x86-64(AMD64/Intel64) 아키텍처는 기존 16비트 및 32비트 x86용 소프트웨어를 수정 없이 그대로 실행할 수 있도록 하위 호환성을 지원합니다.

10번
[문제] (참/거짓) 현재 구현된 64비트 프로세서에서는 64비트 전체를 주소 지정(Addressing)에 사용한다.
[정답] 거짓 (False)
[해설] 현재 실제 64비트 프로세서들은 버스 및 하드웨어 구성의 효율성을 위해 64비트 전체가 아닌 48비트(최신 모델은 52비트) 영역만 가상 주소 지정에 사용합니다.

11번
[문제] (참/거짓) 인텔 아이테니엄(Itanium)의 명령어 세트는 기존 x86 명령어 세트와 완전히 다르다.
[정답] 참 (True)
[해설] 아이테니엄은 x86과 호환되지 않는 IA-64(EPIC/VLIW)라는 독자적인 아키텍처를 사용했습니다.

12번
[문제] (참/거짓) 정적 RAM(SRAM)은 일반적으로 동적 RAM(DRAM)보다 가격이 저렴하다.
[정답] 거짓 (False)
[해설] SRAM은 트랜지스터 4~6개로 1비트를 구성하므로 매우 빠르고 비쌉니다(캐시 메모리로 사용). 반면 DRAM은 트랜지스터 1개와 콘덴서 1개로 구성되어 구조가 간단하고 저렴합니다.

13번
[문제] (참/거짓) REX 접두사가 사용될 때 64비트 RDI 레지스터를 사용할 수 있다.
[정답] 참 (True)
[해설] 64비트 모드에서 기존 32비트 레지스터를 64비트(RDI 등)로 확장하여 접근하거나 신규 레지스터(R8~R15)를 사용할 때 REX 접두사가 사용됩니다.

14번
[문제] (참/거짓) 네이티브 64비트 모드에서는 16비트 리얼 모드(Real mode)를 사용할 수 있지만 가상 8086 모드는 사용할 수 없다.
[정답] 거짓 (False)

15번

[정답] 총 3가지 수준 (하드웨어 포트 레벨, BIOS 서비스 레벨, OS API 레벨)

26번
[문제] 고성능 게임 프로그램들이 사운드 출력을 OS나 드라이버를 거치지 않고 사운드 카드의 하드웨어 포트로 직접 보내는 이유는 무엇인가?
[정답] 지연 시간(Latency) 최소화 및 처리 속도 극대화
[해설] 운영체제 계층 및 드라이버 소프트웨어를 거치는 오버헤드를 건너뛰고 하드웨어를 직접 제어함으로써, 사운드 출력 반응 지연을 줄이고 처리 속도를 가장 빠르게 만들기 위해서입니다.
