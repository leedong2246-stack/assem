Algorithm Workbench 문제도 풀어야 하는지 모르고 늦게 올림 <br>
MSB (Most Significant Bit, 최상위 비트): 이진수에서 가장 왼쪽에 위치한 비트, 부호 비트(0: 양수, 1: 음수) 역할을 합니다. <br>
LSB (Least Significant Bit, 최하위 비트): 이진수에서 가장 오른쪽에 위치한 비트 <br>
Byte	-> 8비트 ->	1바이트 <br>
Word ->	16비트 ->	2바이트 <br>
Doubleword (DWORD) ->	32비트 ->	4바이트 <br>
Quadword (QWORD) -> 64비트 -> 8바이트 <br> 
Double Quadword	-> 128비트 -> 16바이트 <br>
음수를 2의 보수로 만드는 방법 (비트 반전 후 +1) <br>
1. 해당 양수의 이진수를 구합니다. <br>
2. 모든 비트를 반전시킵니다 (0->1, 1->0으로) <br>
3. 1을 더합니다 (2의 보수).<br>
멀티플렉서: 여러 개의 입력선 중 하나를 선택해 단일 출력선으로 연결해 주는 회로입니다. <br>
